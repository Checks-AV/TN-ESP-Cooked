ESP32 Test Console

Simulate device traffic to Ticket Rail without hardware

1 · Heartbeat ping

POST /esp32comms/listen — message_type "ping". Updates last_seen.

2 · Station action

POST /esp32comms/listen — message_type "action". action_name can be a name or a numeric preparation_method_id.

3 · Reset tag

POST /esp32comms/listen — message_type "reset". Clears a tag's current_status back to 'Default'. Only the "Reset" station can perform this.

4 · Counter submit

POST /api/esp/submit — device_mac must belong to the "Counter" station. tag_macs is comma-separated below.

5 · Remote log

POST /esp32comms/log — same shape the Counter ESP32's logMsg() sends. Requires the /log route added to esp32comms.js; check /esp-monitor.html to see it land there too.
