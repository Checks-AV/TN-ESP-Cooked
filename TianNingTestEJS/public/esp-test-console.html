ESP32 Test Console

Simulate device traffic to Ticket Rail without hardware

1 · Register device

POST /esp32comms/register — registers an ESP32 and assigns it to a station.

2 · Heartbeat ping

POST /esp32comms/listen — message_type "ping". Updates last_seen.

3 · Station action

POST /esp32comms/listen — message_type "action". action_name can be a name or a numeric preparation_method_id.

4 · Create order

POST /api/orders — registers a pending order (mimics the game spawning a ticket).

5 · Counter submit

POST /api/esp/submit — device_mac must belong to the "Counter" station. tag_macs is comma-separated below.
